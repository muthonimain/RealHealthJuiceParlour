# Branding assets

Drop your parlour logo here. The app looks for these files (first match wins):

| File | Use |
|------|-----|
| **RealHJPlogo.jpeg** | Current parlour logo (already in use) |
| **logo.png** | Main logo (recommended — square or wide, transparent background) |
| logo.svg | Alternative if you have a vector logo |
| logo.jpg | Photo-style logo |
| logo.webp | Smaller file size |
| favicon.ico | Browser tab icon (optional; 32×32 or 48×48) |

## Quick start

1. Save your logo as **`logo.png`** in this folder (`client/public/branding/logo.png`).
2. Restart the dev server if it is already running.
3. Refresh the browser — the logo appears on the home screen, sign-in pages, and dashboards.

If no logo file is found, the app shows the default leaf icons.

## Tips

- **PNG** with transparent background works best on dark green headers.
- Keep the file under ~500 KB for fast loading.
- Recommended height: at least **200px** for sharp display on the landing page.
